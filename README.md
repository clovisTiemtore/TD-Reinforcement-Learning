# Reinforcement Learning – Practical Assignments

This repository contains practical assignments (TDs) focused on reinforcement learning algorithms, implemented in Python.

## Content
The project is organized into different assignments:

### TD1 – Policy Iteration
- Implementation of the Policy Iteration algorithm
- Application on a grid-based environment

### TD2 – Q-Learning (Taxi-v3)
- Implementation of the Q-learning algorithm
- Training an agent on the Taxi-v3 environment from Gymnasium

## Files
- `TD1/` : Policy Iteration implementation
- `TD2/` : Q-learning implementation
- `q_learning.py` : Q-learning training script
- `example_taxi.py` : Simple test of the Taxi-v3 environment
- `req.txt` : Python dependencies

## Technologies
- Python
- Reinforcement Learning
- Gymnasium (Taxi-v3)
